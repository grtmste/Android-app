A fast, monochrome, editorial theme for Modafie, built for the free Elementor page builder.

== Description ==

Modafie is a lightweight classic theme designed around the free Elementor plugin:

* Sticky header that hides when you scroll down and returns when you scroll up, with a mega menu and an off-canvas mobile menu.
* Announcement bar (rotating or marquee) managed in the Customizer.
* Global colours and fonts live in the Elementor Kit (Site Settings), so the whole site, including the theme header and footer, restyles from one place.
* Footer and (optionally) header can be replaced by any Elementor template.
* Scroll animations triggered by CSS classes (mf-reveal, mf-parallax, mf-marquee, mf-hero-zoom, mf-carousel, mf-hover-zoom, mf-btn-fill, mf-fade-up, mf-stagger). All of them respect prefers-reduced-motion.
* One-click demo import (Appearance → Modafie Setup) that installs Elementor and creates every page, image, menu and template as editable Elementor content. It is safe to run again.
* WooCommerce styling when WooCommerce is active.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → choose modafie-theme.zip → Install → Activate.
2. Click "Import Modafie demo content" in the notice, or go to Appearance → Modafie Setup.
3. Edit any page with "Edit with Elementor".

== Frequently Asked Questions ==

= How do I change colours and fonts? =
Open any page in Elementor → ☰ menu → Site Settings → Global Colors / Global Fonts.

= Can I re-run the import? =
Yes. Media, pages, templates and menus are matched by an internal ID and are never duplicated. Pages you have edited since the import are kept unless you tick "reset".
